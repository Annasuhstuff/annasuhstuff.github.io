Политика конфиденциальности

Fragrance Content Export · обновлено 8 августа 2026

Fragrance Content Export — личный некоммерческий инструмент, которым пользуется один человек: его автор. Приложение не является публичным сервисом, не собирает данные посетителей и не имеет пользователей, кроме автора.

Какие данные обрабатываются

Приложение обращается через официальный Pinterest API v5 только к аккаунту Pinterest его автора и получает оттуда:

  • имя пользователя и тип аккаунта;
  • список досок автора и их названия;
  • сохранённые автором пины: заголовки, описания, личные заметки, ссылки и адреса изображений.

Доступ запрашивается исключительно в режиме чтения. Данные других пользователей не запрашиваются и не обрабатываются.

Где эти данные хранятся

Полученные данные сохраняются в виде файлов на личном компьютере автора. Серверов, баз данных в интернете и облачного хранилища у приложения нет. Токен доступа хранится локально в файле с ограниченными правами и не передаётся никуда, кроме официального API самого сервиса.

Передача третьим лицам

Данные не передаются, не продаются и не публикуются. Приложение не использует аналитику, рекламные сети, трекеры и сторонние сервисы обработки данных.

Файлы cookie

Этот сайт не использует файлы cookie и не собирает статистику посещений.

Хранение и удаление

Данные хранятся локально столько, сколько нужны автору, и удаляются простым удалением файлов. Доступ приложения к аккаунту может быть в любой момент отозван в настройках безопасности аккаунта, после чего приложение теряет возможность получать какие-либо данные.

Изменения политики

При изменении политики обновлённая версия публикуется на этой странице с новой датой.
